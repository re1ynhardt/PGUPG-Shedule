# Расписание ПГУПС (неофициальное)

Flutter-приложение (iOS + Android) для расписания rasp.pgups.ru: список
групп, поиск, избранное, подгруппы, навигация по неделям, расписание по
дням с типом занятия/аудиторией/преподавателем.

## Как приложение загружает страницы

`rasp.pgups.ru` защищён антибот-проверкой: сервер требует токен
(`x-humantoken`), который вычисляется JavaScript'ом прямо на странице —
обычный HTTP-запрос (`package:http`) такой токен получить не может, какие
заголовки/куки ему ни передавай.

Поэтому вместо `http.get(...)` приложение держит один скрытый
[`WebView`](https://pub.dev/packages/webview_flutter) (`lib/widgets/pgups_webview_host.dart`,
смонтирован один раз в `main.dart` через `MaterialApp.builder`, чтобы куки
жили между экранами) и грузит страницы в нём — это настоящий браузерный
движок, он проходит проверку сам, как обычный посетитель сайта.
`lib/services/pgups_web_fetcher.dart` дожидается загрузки страницы (плюс
короткое "тихое окно" на случай, если антибот-скрипт делает повторную
загрузку после установки токена) и забирает готовый HTML через
`document.documentElement.outerHTML`. `lib/services/pgups_http_client.dart` —
тонкая обёртка с тем же интерфейсом (`.get(url)` → `PgupsResponse` со
статусом/телом/заголовками, см. `pgups_response.dart`), так что
`groups_service.dart` и `schedule_service.dart` (парсинг) не менялись
вообще.

## Кэш: всегда офлайн-доступ, гарантированный фоллбэк

Сайт нередко лежит или отвечает медленно, поэтому кэш — не оптимизация, а
основной источник данных:

- **Cache-first при обычном открытии.** И список групп
  (`groups_service.dart`), и расписание (`schedule_service.dart`) сначала
  смотрят в `PgupsCacheService` (`lib/services/pgups_cache_service.dart`,
  на `shared_preferences`, ключ — сам URL страницы). Если запись есть —
  она возвращается мгновенно, без единого обращения к WebView/сети.
- **Фоллбэк на кэш при любой сетевой ошибке.** Сеть трогается только при
  первом запросе конкретной страницы или при явном
  pull-to-refresh/кнопке 🔄 (`forceRefresh: true`). Но даже в этом случае,
  если сайт лёг, недоступен или WebView вернул ошибку — сервис не падает
  наружу с исключением, а тихо возвращает последнюю сохранённую версию
  страницы из кэша. Ошибка всплывает только тогда, когда для этого URL
  ещё вообще ничего не закэшировано (условно — самый первый запуск без
  интернета).
- Успешный сетевой ответ каждый раз перезаписывает кэш этой страницы, так
  что "последняя закэшированная версия" — это всегда самая свежая из
  когда-либо успешно загруженных.

## О парсере

Изначально страница конкретной группы блокировалась у меня как бот-запрос,
поэтому первая версия использовала эвристический (текстовый) разбор. После
того как вы прислали реальный HTML страницы группы, парсер
(`lib/services/schedule_service.dart`) переписан на точные CSS-селекторы под
настоящую вёрстку сайта (тема Metronic, Bootstrap-таблицы):

- каждый день — блок `<table class="table m-table mb-5">`, название дня —
  из `h4.kt-font-dark` внутри таблицы либо из соседнего `<div class="d-block
  d-md-none"><h4>...</h4></div>` (нужно для пустых дней без пар);
- время — `10:45 — 12:15` из `<span>` рядом с номером пары;
- аудитория — из ссылки `a.kt-link` рядом со временем (`ауд. 2-402`);
- предмет — `span.mr-1`, тип занятия (лекция/практика/лаб.) — `span.badge`;
- преподаватель(и) — ссылки `a.kt-link` на `/schedule/teacher/...`; если
  преподаватель указан просто текстом без ссылки (бывает, например
  `доц. Меремсон Ю.Я.`) — берётся как обычный текст;
- подгруппы — кнопки `Подгруппа 1/2`, если у группы они есть;
- неделя — `#kt_dashboard_daterangepicker_date` ("Четная неделя" /
  "Нечетная неделя"), плюс сайт принимает `?start_date=YYYY-MM-DD&end_date=...`
  в URL — на этом построена навигация "вперёд/назад по неделям" в приложении.

Список групп (`lib/services/groups_service.dart`) разбирается со страницы
`https://rasp.pgups.ru/schedule/group`, тоже по реальной вёрстке.

Если сайт когда-нибудь поменяет вёрстку — вся логика разбора расписания
живёт в одном файле, `schedule_service.dart`; на экране расписания есть
кнопка с 🐛 (жук), показывающая сырой HTML страницы, чтобы быстро свериться
и поправить селекторы.

## Запуск

```bash
flutter create --project-name pgups_schedule --org ru.pgups.schedule .
# Это досоздаст стандартные папки android/ и ios/ (в этом архиве их нет —
# сюда включены только lib/ и pubspec.yaml).
# На вопрос "перезаписать pubspec.yaml?" — откажитесь, либо просто
# скопируйте зависимости из готового pubspec.yaml в сгенерированный.

flutter pub get
flutter run
```

Либо, если у вас уже есть пустой Flutter-проект — скопируйте `lib/` и
`pubspec.yaml` из этого архива поверх своих, затем `flutter pub get`.

### Android: разрешение на интернет

`flutter create` уже добавляет
`<uses-permission android:name="android.permission.INTERNET"/>` в
`android/app/src/main/AndroidManifest.xml` по умолчанию — обычно ничего
дополнительно делать не нужно.

### iOS

Специальных настроек не требуется — все запросы идут по HTTPS.

## Возможности

- Список всех групп ПГУПС (очная / заочная / очно-заочная формы), поиск по
  номеру группы, фильтр по форме обучения.
- Избранные группы и последняя/основная выбранная группа (офлайн,
  `shared_preferences`, `favorites_service.dart`) — быстрый доступ сверху
  списка; добавление долгим тапом по группе или звёздочкой на экране
  расписания.
- Расписание по дням недели вкладками: время, номер пары, тип занятия,
  преподаватель(и), аудитория. Длинные списки преподавателей корректно
  переносятся на несколько строк, не вылезая за карточку.
- Переключение подгрупп (если у группы их несколько).
- Навигация по неделям (‹ / ›) — использует `start_date`/`end_date`,
  которые понимает сайт; вверху показывается "Четная/Нечетная неделя" и
  диапазон дат.
- Кэш-первый режим работы и гарантированный фоллбэк на кэш при недоступном
  сайте (см. раздел выше) — расписание и список групп доступны офлайн.
- Pull-to-refresh, понятные экраны ошибок с повтором.
- Debug-экран (🐛) — сырой HTML страницы, для быстрой доводки парсера, если
  сайт поменяет вёрстку.

## Структура

```
lib/
  models/
    group.dart                 # Group
    lesson.dart                # Lesson, ScheduleDay, Subgroup, GroupSchedule
  services/
    groups_service.dart        # список групп: cache-first + фоллбэк на кэш
    schedule_service.dart      # расписание группы: URL, парсинг, недели,
                                # cache-first + фоллбэк на кэш
    favorites_service.dart     # избранное / последняя-основная группа
    pgups_cache_service.dart   # кэш HTML-страниц на shared_preferences
    pgups_http_client.dart     # тонкая обёртка над pgups_web_fetcher
    pgups_web_fetcher.dart     # загрузка страниц через скрытый WebView
    pgups_response.dart        # модель ответа (статус/тело/заголовки)
  screens/
    app_home_screen.dart       # стартовый экран / выбор основной группы
    groups_screen.dart         # список/поиск групп
    schedule_screen.dart       # расписание, подгруппы, навигация по неделям
    raw_debug_screen.dart      # отладочный просмотр сырого HTML
  widgets/
    lesson_card.dart           # карточка занятия
    pgups_webview_host.dart    # скрытый WebView, смонтирован в MaterialApp.builder
  theme.dart
  main.dart
```
